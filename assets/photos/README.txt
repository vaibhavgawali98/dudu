Put your photos here (e.g. memory1.jpg, memory2.jpg, memory3.jpg).
Then list them in config/content.py inside the MEMORIES list.
Recommended: JPG or PNG, resized to under ~1600px on the long edge
and compressed (under ~500KB each) so the site loads fast on mobile.
If a listed file is missing, the app shows a placeholder instead of
crashing, so it's safe to set up your MEMORIES list in advance.
